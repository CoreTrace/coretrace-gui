# CoreTrace Desktop design

CoreTrace is a French-language code and analysis workspace. Keep the existing charcoal surfaces, red primary accent, and compact editor typography. The CSS custom properties in `desktop/styles.css` define the runtime palette.

The workspace header names the active folder and keeps **Analyser** in the same place with or without a file open. Use the shared dialog, focus styles, and text labels for all launch surfaces. Keep the primary action next to the consequence it authorizes.
