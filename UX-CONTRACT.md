# Analysis UX

- Analyse names a folder or supported source file and asks where to run. Local analysis requires no account. The first managed run discloses its required download, official version, and size before the user starts it.
- Cloud analysis discloses the upload before transfer and requires a second explicit approval for CTU. Failure offers a local retry.
- Analysis reads saved files. When the target contains edits, its action states that it saves them first. A save failure keeps the editor drafts and stops the launch.
- The run panel keeps progress, cancellation, recovery, and report access visible. Local reports belong to the workspace and run that created them.
- Updating Desktop or its analyser requires an explicit action for each. A managed analyser stays available offline after install, and a manually selected analyser remains the user's choice.
