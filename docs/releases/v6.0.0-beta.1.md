## What's new in v6.0.0-beta.1

CoreTrace Desktop is a **new application**. The Electron GUI of the 5.x line has been rewritten on Tauri and React: a native window, a 4 MB installer where 5.1.0's was 369 MB, and the whole CoreTrace platform inside it — analyses run in the cloud with your CTU, or on your machine with your own ctrace.

**Analyse anywhere, one button**
- **Nouvelle analyse** analyses the open folder in the cloud when you have an organisation to bill, and on this machine otherwise — or when the platform refuses. The same button in the sidebar, on the home page and in the Analyses tab.
- In the editor, **Analyser** opens a menu: *Sur cette machine* (this file) or *Dans le cloud* (the folder). With unsaved changes it saves first.
- A cloud run stops at its price. You are asked to accept the CTU cost before anything is spent, wherever you are in the app; a finished run offers its results rather than interrupting you.
- The status bar shows what a run is doing and for how long — packing, upload, quoting, running — with a real estimate of the remaining time, measured from your own previous analyses, and a way to stop it.

**Results you can read**
- Findings grouped **Erreurs → Avertissements → Notes**, each row a single click to the line in the editor.
- The history keeps every analysis, cloud and local, per folder, with its verdict and cost. Opening a past analysis shows its findings.
- A local run that produced nothing says why: the exit code, the first error line, and — before you even run — which of ctrace's tools are missing on this machine (*Paramètres*).

**A workspace, not just a viewer**
- Several folders open at once, each collapsible, VS Code-style. Tabs are remembered per folder; the folders and your ctrace path are remembered across sessions.
- **Ctrl+P** opens a file by name.
- Clone a GitHub repository straight into the app; connect GitHub from *Paramètres* without leaving it.

**When a tool fails, tell us**
- A local run whose tools did not complete offers **Envoyer un rapport**: the full tool log, your answer to *"Quelles librairies utilisez-vous ?"*, and your build files (Makefile, CMakeLists.txt…), pre-selected. The data stays private and is read only to improve the tools. Five reports a day per account.

**Also**
- French throughout, including errors from the platform and the tools.
- Sign in with Google or GitHub; the desktop keeps your session in the system keychain.
- Repositories page shows six at a time with search across all of them; cards say *Cloner et ouvrir* or *Ouvrir* depending on whether a copy is already here.

### Downloads

Pick the installer for your OS below.

- **Windows** — `CoreTrace_6.0.0-beta.1_x64-setup.exe`
- **macOS** — `CoreTrace_6.0.0-beta.1_universal.dmg`. The build is unsigned: on first launch, right-click the app and choose **Open**, or run `xattr -cr /Applications/CoreTrace.app`.
- **Linux** — `.deb` or `.AppImage`.

### Before you rely on local analysis

Cloud analysis works everywhere with a CoreTrace account. **Local analysis needs a `ctrace` binary on your machine**, chosen once in *Paramètres*:

- **Linux**: download it from the [ctrace releases](https://github.com/CoreTrace/coretrace/releases) (v0.74.0, amd64/arm64).
- **Windows and macOS**: there is no published ctrace binary yet; build it from source or use cloud analysis. The desktop tells you which of ctrace's tools (cppcheck, flawfinder, tscancode, ikos) are missing and reports nothing as "clean" when a tool did not run.

### Not in this version

Compared with the 5.x Electron GUI: the integrated terminal, the AI assistant and project-wide search are not in this rewrite yet. Automatic updates are not enabled: download the next version from this page.

This is a **beta**. Report anything odd from the app itself — that is what the report button is for.
