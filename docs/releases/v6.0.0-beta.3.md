## What's new in v6.0.0-beta.3

**Automatic updates**
- CoreTrace now checks for a new version when it starts. When one is available, it asks before installing it and restarts on the new version; *Plus tard* keeps the current one until the next launch.
- Updates are signed: the app refuses any package that was not signed with the CoreTrace release key.
- beta.2 has no updater, so this version must be installed by hand one last time. From here on, the app updates itself.

**About and licences**
- *Paramètres* has a new **À propos** panel with the installed version and the licence (Apache 2.0).
- **Licences open source** opens the licence texts of every third-party component shipped in the app. The same file, `THIRD_PARTY_NOTICES.txt`, is installed next to the application.

**Fixes**
- A cloud analysis refused by the platform now says why, after the title: which limit refused it and by how much, for example the CTU missing for the run.
- *Paramètres* showed a stale version number; it now reads the real one.

### Downloads

Pick the installer for your OS below.

- **Windows** — `CoreTrace_6.0.0-beta.3_x64-setup.exe`
- **macOS** — `CoreTrace_6.0.0-beta.3_universal.dmg`. The build is unsigned: on first launch, right-click the app and choose **Open**, or run `xattr -cr /Applications/CoreTrace.app`.
- **Linux** — `.deb` or `.AppImage`.

The `.sig`, `.tar.gz` and `latest.json` files are used by the updater; you do not need them.

### Before you rely on local analysis

Cloud analysis works everywhere with a CoreTrace account. **Local analysis needs a `ctrace` binary on your machine**, chosen once in *Paramètres*:

- **Linux**: download it from the [ctrace releases](https://github.com/CoreTrace/coretrace/releases) (v0.74.0, amd64/arm64).
- **Windows and macOS**: there is no published ctrace binary yet; build it from source or use cloud analysis. The desktop tells you which of ctrace's tools (cppcheck, flawfinder, tscancode, ikos) are missing and reports nothing as "clean" when a tool did not run.

This is a **beta**. Report anything odd from the app itself — that is what the report button is for.
