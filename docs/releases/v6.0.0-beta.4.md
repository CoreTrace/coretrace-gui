## What's new in v6.0.0-beta.4

- Folder analysis now displays findings from all analysed files. Running the ATP workspace shows seven findings across six source files.
- In the code editor, Ctrl+F (Cmd+F on macOS) opens the search box, highlights matches, and shows the match count.
- The updated acceptance test kit gives each tester a separate Docker image keyed to their user ID and lets the app save edits to the mounted dataset.

### Downloads

Choose the Windows x64 installer, universal macOS disk image, or Linux amd64 Debian package or AppImage below. Existing beta.3 installations can use the in-app updater.

For the acceptance test, download the [workbook](https://github.com/CoreTrace/coretrace-gui/raw/refs/tags/v6.0.0-beta.4/atp/CoreTrace-GUI_ATP.xlsx) and [appendices ZIP](https://github.com/CoreTrace/coretrace-gui/raw/refs/tags/v6.0.0-beta.4/atp/CoreTrace-GUI_ATP_appendices.zip). The ZIP includes the Docker setup and dataset. The image installs the published desktop package and ctrace v0.85.0.
