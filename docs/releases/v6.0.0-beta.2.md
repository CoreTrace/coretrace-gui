## What's new in v6.0.0-beta.2

The Linux packages that v6.0.0-beta.1 promised but never shipped. The application itself is unchanged from that release.

The beta.1 build produced the Windows installer and the macOS disk image and then aborted on Linux: the bundler looks for a square icon to use as the AppImage icon, and the only one it was given measured 524x519. The deb and the AppImage were never built, so the release page offered two downloads where its notes described four. The icons are now square, at 32, 128, 256 and 512 pixels, and the check that would have caught this runs on every push rather than only when a tag is cut.

If you are already running beta.1 on Windows or macOS, there is nothing here for you.

---

### Downloads

Pick the installer for your OS below.

- **Windows** — `CoreTrace_6.0.0-beta.2_x64-setup.exe`
- **macOS** — `CoreTrace_6.0.0-beta.2_universal.dmg`. The build is unsigned: on first launch, right-click the app and choose **Open**, or run `xattr -cr /Applications/CoreTrace.app`.
- **Linux** — `.deb` or `.AppImage`.

### Before you rely on local analysis

Cloud analysis works everywhere with a CoreTrace account. **Local analysis needs a `ctrace` binary on your machine**, chosen once in *Paramètres*:

- **Linux**: download it from the [ctrace releases](https://github.com/CoreTrace/coretrace/releases) (v0.74.0, amd64/arm64).
- **Windows and macOS**: there is no published ctrace binary yet; build it from source or use cloud analysis. The desktop tells you which of ctrace's tools (cppcheck, flawfinder, tscancode, ikos) are missing and reports nothing as "clean" when a tool did not run.

### Not in this version

Compared with the 5.x Electron GUI: the integrated terminal, the AI assistant and project-wide search are not in this rewrite yet. Automatic updates are not enabled: download the next version from this page.

For everything the 6.0 line introduces, see the [v6.0.0-beta.1 notes](https://github.com/CoreTrace/coretrace-gui/releases/tag/v6.0.0-beta.1).

This is a **beta**. Report anything odd from the app itself — that is what the report button is for.
